# Project Overview
Graphence aims to help developers understand unfamiliar repositories by extracting code structure and relationships, indexing source and documentation, answering questions with evidence, and generating project documentation.

## Planned outputs
- Repository summary, languages, frameworks and folder structure
- Files, functions, classes, imports, routes and models
- Interactive code knowledge graph
- AI Q&A with source references
- Generated project/module/API documentation
- Change-impact suggestions

## Three input methods
GitHub URL and ZIP enter the code-ingestion pipeline. Existing PDF/DOCX/TXT/Markdown files enter a separate document-ingestion pipeline. Both feed shared retrieval.
